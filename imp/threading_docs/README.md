# Threading Concepts

This folder contains Markdown files that explain the key concepts of threading in Python.

## Contents

- `threads_and_lifecycle.md` — basic thread concepts, thread creation, lifecycle, and daemon threads.
- `synchronization.md` — synchronization primitives such as `Lock`, `RLock`, `Condition`, `Semaphore`, `Event`, and `Barrier`.
- `python_gil_and_performance.md` — Python-specific threading behavior, the Global Interpreter Lock, and performance trade-offs.
- `common_problems_and_patterns.md` — race conditions, deadlocks, thread-safe patterns, and best practices.

## How to use

Read these files in order to build a complete understanding of threading:

1. `threads_and_lifecycle.md`
2. `synchronization.md`
3. `python_gil_and_performance.md`
4. `common_problems_and_patterns.md`
